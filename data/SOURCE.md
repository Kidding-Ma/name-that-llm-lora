# Bundled competition inputs

Source: https://www.kaggle.com/competitions/name-that-llm/data

Included from the owner's existing download: train.csv, test.csv, sample_submission.parquet.
The training file contains 2699 labeled passages across 150 prompts. The public test contains
3 example rows. Full hidden-test data is supplied by Kaggle when it reruns a code submission.

The repository's MIT license covers its code; competition data remains subject to its original
dataset terms and competition rules. See manifest.json for exact SHA-256 values and file sizes.

Training and local sample prediction can use these files directly, with no Kaggle account credential.
